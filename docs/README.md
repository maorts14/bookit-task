# BookIt Knowledge Base

The knowledge base keeps domain language, architecture decisions, conceptual data-model material, API contracts, and authentication guidance discoverable and current.

- [`context.md`](./context.md): canonical domain vocabulary.
- [`architecture/`](./architecture/): architecture explanations and decision records in `adr/`.
- [`data_models/`](./data_models/): conceptual entities, relationships, and business rules; Django migrations remain the executable schema.
- [`api_definition/`](./api_definition/): the authoritative API contract and supporting consumer notes.
- [`auth/`](./auth/): authentication, authorization, and security-policy documentation.
